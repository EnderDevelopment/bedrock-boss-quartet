# Minecraft Bedrock Boss Behavior Pack

Bedrock Boss Quartet is a Minecraft Bedrock Edition behavior pack for Android that adds four summonable boss mobs with distinct health, melee damage, movement, and passive combat effects. The bosses use the vanilla piglin brute model.

## Install

1. Place `create_mcpack.py` and the pack files in the same folder.
2. Run `python create_mcpack.py` to create `FourRealmsBosses.mcpack`.
3. Open the `.mcpack` file on your Android device and select Minecraft to import it.
4. In your world settings, enable the Four Realms Bosses behavior pack and turn on cheats.

## Use

Summon a boss in chat with cheats enabled:

- `/summon fourrealms:ember_tyrant` — 420 health, 11 melee damage, fire immunity and fire resistance.
- `/summon fourrealms:tide_hydra` — 700 health, 13 melee damage, water breathing and regeneration.
- `/summon fourrealms:void_reaver` — 260 health, 22 melee damage, fast movement, speed and resistance.
- `/summon fourrealms:storm_colossus` — 540 health, 15 melee damage, high knockback resistance and resistance.
